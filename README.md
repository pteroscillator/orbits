# Orbits

Two stars, two planets and three moons circling each other in 3D, with sliders for every size, speed and orbit. Drag up or down to tilt the view, scroll to zoom. No sound. Made for a computer with a mouse.

Live: https://pteroscillator.github.io/orbits/

Browsers tested: Safari and Firefox on macOS
